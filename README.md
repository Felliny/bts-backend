# 📃 Fintech Transaction API

# 🚀 Overview
This project is a robust RESTful API developed as the backend core for a digital banking system. It simulates essential financial operations, focusing on data integrity, transaction safety, and scalability.

The system is designed to handle user accounts, secure transfers, and transaction history tracking. This repository serves as the server-side application, which is built to be consumed by a future Frontend client (React).

# 🛠️ Technologies & Tools

- Java 17 
- Spring Boot 
- Spring Data JPA
- MySQL
- Maven
